06 — Motion
Motion Principles
Motion is functional, not decorative. Transitions must communicate state — never delay or distract. Data tables never animate. Hover over each card to preview.
Instant — 0ms
--duration-instant
Focus ring appearance. Checkbox checks. Toggle state. Any interaction that feels tapped, not animated.
Fast — 100ms
--duration-fast
Button hover fills. Nav item highlights. Chip color changes. All micro-interactions.
Normal — 150ms
--duration-normal
Sidebar collapse. Toast slide-in. Dropdown open. The default for most UI transitions.
Slow — 250ms
--duration-slow
Modal entrance. Drawer slide. Page-level transitions. Use sparingly — never on repeated actions.
Easing standard: cubic-bezier(0.4, 0, 0.2, 1) — the Material ease-in-out equivalent. Provides quick acceleration from rest and smooth deceleration to stop. Never use spring physics or bounce easing on data-dense interfaces — it reads as frivolous in a professional ERP context.
07 — Writing
Voice & Tone
Parwest writes like a competent senior colleague — direct, precise, never condescending. Copy earns trust through accuracy, not warmth.
Personality
Authoritative — We know what we're doing. Commands are clear and unambiguous.
Precise — Every label earns its place. No filler words. Numbers are exact.
Trustworthy — We tell the user when something goes wrong. Errors are honest, not euphemistic.
Confident — We don't hedge. "Guard cannot be deployed" not "There may be an issue with deploying."
Formulas
Buttons: Verb-first, ≤3 words. "Deploy Guard" · "Lock Region" · "Generate Invoice"
Errors: What happened + why + what to do. "Guard cannot be deployed — lifecycle status is INACTIVE. Change status to ACTIVE first."
Empty states: What this is + why empty + action. "No deployments found · This client has no active guard assignments · Deploy a Guard"
Confirmations: Summarize impact. "Lock Lahore – Gulberg? 47 payroll records will be locked for April 2026."

Focus Ring
Status chips, buttons, inputs, and all interactive elements must show --focus-ring on keyboard focus: 0 0 0 3px rgba(47,91,255,.35).
Status signals
Every status chip includes a label — never just a colored dot. The dot is a redundant reinforcement, not the primary signal. Guard lifecycle chips always show the text: "Active", "Pending", etc.
Keyboard model
Every primary workflow must be completable without a mouse. Data tables: J/K for row navigation, / to focus search, Space for row select. Forms: Enter to advance step.
